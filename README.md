# Messaging System 
The goal of this project was to create a messaging system that could receive messages on behalf of a business, process them in an intelligent manner, and submit a reply that is grounded in the business's details. In particular the system was designed to handle potential customers that message the business first, from an advertisement on a meta platform, a website quote request form, or directly to the businesses meta accounts. 

This system was built and deployed into production for the business Filthy Wraps LLC and in a span of 3 months has booked 830 service based jobs to the businesses calendar. During this time the output tokens per month was around 8M with an average cost per month of $27.
